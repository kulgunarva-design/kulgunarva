# Объявления кооператива

Редактируйте `coop-events-data.js`: каждая запись в массиве `window.COOP_EVENTS` — отдельное мероприятие.

Поля: `id` (уникальное имя латиницей), `title`, `date` (ГГГГ-ММ-ДД), `time` (например, 10:00), `location`, `body`. Название, место и описание можно задавать строкой или объектом с переводами `ru`, `et`, `en`. При отсутствии перевода показывается русский текст.

Если точная дата неизвестна, оставьте `date` пустым. При необходимости укажите `year`. Не придумывайте дату и место: страница покажет «Будет объявлено».

После сохранения загрузите файл на GitHub. Мероприятия с прошедшей датой автоматически перемещаются в архив по времени Эстонии. Для изменения даты отредактируйте существующую запись, сохраняя её `id`.

Первая запись о собрании в 2027 году перенесена из контактов; точные дата, время и место в исходном сайте отсутствовали.
